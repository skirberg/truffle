# Security

## Reporting a vulnerability

Please report it privately through GitHub's private vulnerability reporting: open the **Security** tab of
this repository and choose **Report a vulnerability**. Please don't open a public issue, pull request or
discussion for a security problem.

Say what you found, where (a URL on truffle.city or a file and line here), and how to reproduce it. You'll
get an answer there.

## Scope

The site at https://www.truffle.city and the code in this repository. The data pipeline and the hosted
database are not in this repository.

## What the site holds

No accounts, no passwords and no payments. A visitor's calls are kept only in their own browser. The site
reads public property records; it never asks the county for owner names, mailing addresses, homestead or
exemption status, or sales.
